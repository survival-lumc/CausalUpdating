# Interventional updating of time-to-event prediction models

R code repository for the paper *"Interventional updating of time-to-event prediction models"*.

## Contents

The repository contains the following:

- **`updating-causal.R`**: main R script which reproduces all analysis of the manuscript;

- **`SimulationFunctions.R`**: R script with the functions used in the analysis;

- **`plots_and_tables.R`**: R script used for creating the plots and tables of the manuscript.
